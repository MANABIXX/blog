# 技術・IT：Webとインターネット

## インターネットとWeb

- インターネット：世界中のネットワークを相互につないだ仕組み
- Web（World Wide Web）：インターネット上で、文書や画像などをリンクでたどって利用する仕組み

Webはインターネットを利用するサービスの一つ。電子メールなど、Web以外のインターネット利用もある。

## Webページが表示される流れ

1. ブラウザーにURLを入力する
2. DNSなどを使って接続先の情報を調べる
3. ブラウザーがサーバーへHTTP/HTTPSでリクエストを送る
4. サーバーがHTML・CSS・画像などを返す
5. ブラウザーが内容を組み立てて表示する

## 役割の違い

- HTML：文章や見出しなど、ページの構造
- CSS：色・配置・文字サイズなど、見た目
- JavaScript：ボタン操作や表示更新など、動き
- URL：Web上の資源の場所を示す
- HTTPS：通信を暗号化し、相手の確認などを行う仕組み

## 注意点

- ブラウザーと検索エンジンは別物
- Webサイトとインターネットは同じ意味ではない
- HTTPSでも、サイトの内容そのものが必ず安全とは限らない
