# MANABIXX 要点まとめ

教科の要点を、**定義 → 公式・仕組み → 具体例 → 間違えやすい点**の順で確認できる学習ノートです。各ページは短く区切り、関連ページをリンクでつないでいます。

## 教科から探す

- [[数学]] — 方程式・関数・文章題の考え方
- [[理科]] — 法則・回路・化学変化・実験
- [[社会]] — 憲法・選挙・統計資料の読み取り
- [[英語]] — 文法・語法・例文
- [[技術・IT]] — Web・コンピューターの仕組み

## 使い方

1. まず教科ページで単元を選ぶ
2. 要点ページで定義・公式・条件を確認する
3. 関連リンクからつながる知識を読む
4. 最後にMANABIXX本体の問題演習で理解を確かめる
