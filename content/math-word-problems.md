文章題が苦手なとき、計算力より先に「文章のどこを式にすればよいのか」で止まっていることがあります。数字を見つけてすぐ計算するのではなく、**何を求めるのか、何と何が等しいのか**を先に整理すると、式を作りやすくなります。

## 1. 最初に「求める量」を一つ決める

問題を読んだら、いきなり式を書かずに、最後に何を答えるのかを確認します。

たとえば「ペンを何本買ったか」を求めるなら、ペンの本数を (x) 本と置きます。分からない量を文字で表すと、文章の中の数量を同じ基準で比べられます。

文字を置くときは、単位も一緒に書いておくと混乱しにくくなります。

- (x)：ペンの本数（本）
- ペン1本の値段：120円
- ノート2冊の代金：360円

## 2. 条件を「一つずつ」式にする

次の問題を考えてみます。

> 1本120円のペンを何本かと、1冊180円のノートを2冊買ったところ、代金の合計は660円でした。ペンは何本買いましたか。

文章を数量に分けると、次のようになります。

| 文章の情報 | 数量 |
|---|---:|
| ペンを (x) 本買う | (120x) 円 |
| ノートを2冊買う | (180	imes2=360) 円 |
| 合計金額 | 660円 |

「ペンの代金＋ノートの代金＝合計金額」なので、

[
120x+360=660
]

という方程式になります。

## 3. 計算したあと、文章に戻して確かめる

[
120x+360=660
]

両辺から360を引くと、

[
120x=300
]

両辺を120で割って、

[
x=2.5
]

となります。ここで、ペンの本数が整数にならないことに気づきます。つまり、この例の数字では「何本買ったか」という条件と合いません。計算だけを終わらせず、問題文の条件と答えが合うかを確認する必要があります。

この例は、式を立てる練習として数字を置いたものです。実際の問題では、答えが本数・人数・個数などの整数になるかも確認しましょう。

## 4. 式を作れないときの確認順

式が思いつかないときは、次の順番で整理します。

1. **求める量に線を引く**：最後に何を答えるのかを決める。
2. **分かっている量を表にする**：数字、単位、条件を分ける。
3. **同じ単位にそろえる**：円と円、cmとcmのように比べられる形にする。
4. **関係を言葉にする**：「合計」「差」「同じ」「何倍」などを使って関係を説明する。
5. **説明を式に置き換える**：言葉で言えた関係を数式にする。

「合計」は足し算、「差」は引き算と機械的に覚えるだけでは不十分です。何を足すのか、どちらからどちらを引くのかまで確認します。

## よくあるつまずき

| つまずき | 見直すこと |
|---|---|
| 数字を全部掛けてしまう | それぞれの数字が何を表すか書く |
| (x) の意味を途中で忘れる | 文字の横に単位と意味を残す |
| 合計と差を取り違える | 「何と何を比べているか」を文章で言う |
| 答えの単位を書き忘れる | 最初に求める量の単位を確認する |
| 計算結果だけで終える | 元の文章に代入して条件を満たすか確かめる |

## 仕上げの練習

「1冊150円のノートを何冊か買い、80円の消しゴムを1個加えると、合計は530円でした。ノートは何冊ですか。」

ノートの冊数を (x) と置けば、

[
150x+80=530
]

となります。両辺から80を引くと (150x=450)、したがって (x=3) です。

文章題では、式を立てる前の整理が半分です。答えを急がず、求める量・条件・数量の関係を順番に確認してみてください。
